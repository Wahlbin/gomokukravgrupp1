# UC-09: Ändra Ljudinställningar

## Aktör
Spelare

## Mål
Att det ska gå att ändra spelets ljudinställningar utifrån varje spelares preferens.

## Förutsättningar
- Spelaren befinner sig på spel sidan eller i spelets app.

## Huvudflöde
1. Spelaren öppnar huvudmenyn.
2. Spelaren klickar på "Inställningar" i menyn.
3. Spelaren klickar på "Ljud inställningar" i inställnings menyn.
4. Spelaren drar i slidern för att justera spelets ljud nivå utifrån preferens

## Alternativa flöden
- Spelaren skriver manuellt in ljud nivån
	1. Spelaren klickar på numret som representerar ljud nivån
	2. Numret blir till en ruta
	3. Spelaren skriver in det exakta numret dem vill ha som ljud nivå
- Spelaren ångrar sig
	1. Spelaren klickar på "Återställ inställningar"
	2. Inställningarna återställs till default

## Resultat
Spelaren kan justera ljud nivån i spelet utifrån sin egen preferens eller känslighet.
